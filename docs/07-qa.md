## 2. What is actually being tested

Coverage percentages say little. These are the tests that would catch a real
failure.

### The credential — the reason this build exists

| Test | Proves |
|---|---|
| `voice.test.js` "never returns anything resembling an API key" | Even a provider that leaks a key into its own return value cannot get it past the controller's allowlist |
| `elevenlabs.provider.test.js` "sends the key in the header and returns a session without it" | The key travels on exactly one hop, to one host, and is absent from the result |
| `portfolio.spec.ts` "ships no credential to the browser" | The built page contains nothing matching `xi-api-key`, `sk_…`, or an ElevenLabs key name |
| `voice.test.tsx` "opens the socket with a signed URL and never a key" | The SDK is called with `signedUrl` and no credential-shaped property |

### The content — a broken portfolio is worse than a broken feature

`content.test.ts` walks every project and asserts:

- all 100+ artwork, video, audio and sprite paths resolve to files that exist on disk
- every image has alt text longer than five characters
- nothing with sound is set to autoplay
- the three tree projections are one triptych of three, never a sequence
- the Khushi Ya Majboori content note appears **before** the images it gates
- the CAT gate shows three previews and holds ten
- the password is not in the bundle
- exactly one project overrides the amber ground (LIMINAL)
- every credit line BUILD_SPEC §10 requires is present
- no Urdu appears in interface copy, and every Urdu run in prose carries `lang` and `dir`

### The interaction

`console.test.tsx` covers the state machine: eleven readable titles on load,
selection wrap, channel clamp, keyboard equivalents, load → card → full,
B backing out one stage, START shutdown and boot, row clicks, and that typing in
a text field is never hijacked.

### The failure paths

`resilience.test.js` proves the breaker opens after the threshold and then stops
calling through entirely; that a 4xx does **not** open it (our fault says nothing
about upstream health); that a 4xx is never retried; and that a 5xx is.

## 8. Known gaps

1. **No visual regression testing.** A CSS change could shift the console's
   pixel-locked geometry without failing a test. Mitigated by
   `docs/reference/legacy/site/` being available to diff against. Worth adding
   Playwright screenshot comparison if the design starts changing.
2. **The ElevenLabs conversation itself is not tested end-to-end.** Tests stop at
   "a valid signed URL was requested and passed to the SDK". Testing further
   would mean a real billable session in CI. The handshake is covered; the
   conversation is a manual check on the release checklist.
3. **No load test.** Justified above.
4. **Coverage floors are moderate** (70/65). Raising them would mostly buy tests
   of `server.js` bootstrap and pino configuration, which is coverage theatre.
